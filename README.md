Лабораторная работа №1 по курсу «Обработка изображений».

Веб-приложение для загрузки, просмотра и сохранения изображений в форматах PNG, JPEG и GB7.

- Загрузка изображений PNG, JPEG, GB7
- Отображение на HTML5 Canvas
- Сохранение в PNG, JPEG, GB7 (с маской и без)
- Drag & Drop с визуальной индикацией
- Строка состояния с информацией о размере и глубине цвета
- Уведомления о действиях пользователя
- Темная тема в стиле Adobe Photoshop
- Адаптивный дизайн
- Горячие клавиши (Ctrl+O — открыть, Ctrl+S — сохранить)

## Формат GB7

GB7 (GrayBit-7) — учебный формат изображений без сжатия:

- **7 бит** на значение серого (0–127)
- **1 бит** опциональной маски прозрачности
- Заголовок: сигнатура `GB7·` (4 байта) + метаданные (8 байт)
- Данные пикселей построчно без выравнивания

### Структура файла

| Смещение | Размер | Описание              |
|----------|--------|-----------------------|
| 0        | 4      | Сигнатура `GB7·`      |
| 4        | 1      | Версия (0x01)         |
| 5        | 1      | Флаги (бит 0 — маска) |
| 6        | 2      | Ширина (big-endian)   |
| 8        | 2      | Высота (big-endian)   |
| 10       | 2      | Резерв (0x0000)       |
| 12       | W×H    | Данные пикселей       |
